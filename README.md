# Syncy

Syncy is an all-in-one productivity app designed to streamline your daily tasks and organize your digital life. With robust features such as encrypted MySQL data storage, Laravel backend, and Flutter for Android and desktop versions, Syncy is your go-to solution for managing accounts, keys, visas, notes, todos, contacts, mails, and files with ease.

## Features

- **Departmental Organization**: Categorize and manage your data efficiently with dedicated departments for accounts, keys, visas, notes, todos, contacts, mails, and files.

- **Categories and Sorting Views**: Customize your experience with flexible categories and sorting options within each department, ensuring a personalized and organized workflow.

- **Secure MySQL Data Storage**: All your sensitive information is securely encrypted and stored using MySQL, providing a high level of data security.

- **Laravel Backend**: Powered by Laravel, Syncy ensures a robust and scalable backend infrastructure, delivering a seamless user experience.

- **Flutter for Android and Desktop**: Enjoy the convenience of accessing Syncy on both Android devices and desktop platforms, offering a consistent user interface across different environments.

## Getting Started

To get started with Syncy, follow these steps:

1. Clone the repository:

```bash
git clone https://github.com/EngALAlfy/syncy-backend.git
```

2. Set up the Laravel backend by following the instructions in the `backend\/README.md` file.

3. Configure the MySQL database to ensure secure encrypted data storage.

4. Build and run the Flutter app on your Android device or desktop environment. Refer to the `flutter\/README.md` file for detailed instructions.
